# 即売会マップエディター（otakara-map-editor）

同人誌即売会などの会場マップ画像上に、サークル配置情報を吹き出し形式で追加できるシングルページアプリ。

**公開URL**: https://yuratomaru.github.io/toy-box/otakara-map-editor/

---

## 主な機能
----

- **会場マップの読み込み**: PNG / JPEG などの画像を読み込み（ボタン、または画面へドラッグ＆ドロップ）
- **吹き出しの配置**: 「配置・スペース」と「サークル名」を入れた吹き出しを、マップ上の好きな位置に置いて矢印（アンカー）でスペースを指す
  - 複数行をまとめて追加、スプレッドシートからの貼り付けにも対応
- **カテゴリ・凡例**: カテゴリごとに色と白黒印刷用の模様（8種類）を設定し、凡例をマップに表示
- **整列**: 複数選択した吹き出し（またはアンカー）のうち、位置が近いものだけを横一列／縦一列に揃える
- **画像の編集**: 回転、切り抜き、拡大縮小、モノクロ化、明るさ・コントラスト調整。編集後は吹き出しの位置が自動で追従し、取り消しもできる
- **PNG書き出し**: 書き出し範囲・背景の透過・解像度（1〜3倍）を選んで保存
- **データの保存・復元**: 配置データと元画像をZIPにまとめて保存し、後で読み込み直せる
- **元に戻す / やり直し**、**自動保存**（ブラウザ内）

## 基本の使い方
----

1. **画像を読み込む**: ヘッダーの「画像を読み込む」を押すか、画面中央のガイドへ画像をドロップします（長辺8,000px以内・25MB以下）。
2. **吹き出しを置く**: 右パネルの「吹き出しを連続追加」に「配置・スペース」「サークル名」を入力し、「マップにまとめて配置」を押します。
   マップの何もない所をダブルクリック（スマホは長押し）して、1つずつ置くこともできます。
3. **位置を合わせる**: 吹き出しをドラッグして動かし、先端の丸（アンカー）をドラッグして対象のスペースに合わせます。
4. **カテゴリで色分けする**: 右パネルの「カテゴリ・凡例設定」で、カテゴリ名・色・模様を決めます。吹き出しの所属カテゴリは「選択中の吹き出し編集」で変えられます。
5. **保存する**:
   - 画像として使う → 「画像として保存 (PNG)」
   - 後で続きを編集する → 「データを保存 (.zip)」

保存のたびに、保存名を入力するダイアログが表示されます。

## 操作ガイド
----

### 吹き出しを追加する

| 操作 | 内容 |
|---|---|
| 連続追加欄に入力 → 「マップにまとめて配置」 | 入力した行をまとめて配置（`Ctrl/⌘ + Enter` でも実行） |
| `Enter` / `Tab` | 次の行・次の欄へ移動（最終行で新しい行が増える） |
| スプレッドシートからコピーして貼り付け | 1列目＝配置・スペース、2列目＝サークル名として複数行を一度に入力 |
| マップをダブルクリック（スマホは長押し） | その位置に1つ追加して、すぐ名前を入力できる |

### 選択・移動

| 操作 | 内容 |
|---|---|
| クリック | 吹き出しを選択（`Ctrl/⌘ + クリック` で複数選択） |
| 「範囲選択」モード、または `Shift + 背景をドラッグ` | 囲んだ吹き出しをまとめて選択 |
| `Ctrl/⌘ + A` | すべて選択 |
| ドラッグ | 吹き出しを移動（選択中は全部まとめて動く） |
| `Shift + ドラッグ` | 吹き出しと矢印の先（アンカー）をいっしょに移動 |
| アンカー（丸）をドラッグ | 矢印の先だけを移動 |
| 配置データ一覧のクリック | 一覧から吹き出しを選択 |

### 編集

| 操作 | 内容 |
|---|---|
| 吹き出しをダブルクリック（スマホは長押し） | その場で配置・サークル名・カテゴリを編集 |
| 吹き出しを右クリック（PCのみ） | メニューから名前・サイズ・カテゴリの変更、複製、削除 |
| 右パネル「選択中の吹き出し編集」 | 配置・サークル名・幅・高さ・カテゴリを変更、複製、削除 |
| `Ctrl/⌘ + D` | 複製 |
| `Delete` / `Backspace` | 削除 |
| `Esc` | 選択を解除 |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z`（`Ctrl/⌘ + Y`） | 元に戻す / やり直し |
| `Ctrl/⌘ + P` | 「画像として保存」を開く |

### 整列（2つ以上を選択したとき）

右パネルに「近いものを整列」が表示されます。

- **対象**: 「吹き出し」または「アンカー」を選びます。
- **横一列 / 縦一列**: 上下（または左右）の位置が近いものだけが同じグループになり、そのグループの平均位置に揃います。離れているものは動きません。
- **近さ**: スライダーで、どのくらい離れていても「近い」とみなすかを調整します（画像のサイズに合わせて調整してください）。
- 整列も `Ctrl/⌘ + Z` で元に戻せます。

### 表示の操作

| 操作 | 内容 |
|---|---|
| マウスホイール / ピンチ | ズーム |
| 背景をドラッグ | 表示位置を移動 |
| ＋ / － / 全体表示ボタン | ズームの切り替え、全体を表示 |
| ごみ箱ボタン（マップ右下・赤） | すべての吹き出しを削除（確認あり。直後なら元に戻せます） |
| ヘッダーの月・太陽ボタン | ライト/ダークテーマの切り替え（初期値は端末の設定に従う） |

スマホ・タブレットでは、左上のメニューボタンからヘッダーの機能を呼び出し、右パネルは画面下のシートとして上下に開閉します。

## カテゴリ・凡例
----

- カテゴリは最低1つ必要です。「＋新しいカテゴリを追加」で増やし、カテゴリ名・ベースカラー・模様を設定します。
- 模様は「なし／水玉／斜線1・2／斜め格子／方眼格子／十字／波線」から選べます。白黒印刷しても区別がつきます。
- 「おすすめセット」から、色覚の多様性に配慮した配色（CUD対応）をワンクリックで適用できます。
- 「凡例をマップに表示」にチェックを入れると、凡例がマップに表示されます（ドラッグで位置を移動可能）。凡例は、吹き出しが1つ以上あるカテゴリだけ載ります。
- 「全体デザイン設定」で、吹き出しのスタイル（標準＝点線／漫画風＝ツノ付き）とサイズ（小65%・中100%・大150%）を切り替えられます。

## 画像を編集する
----

ヘッダーの「画像を編集」から、読み込んだ画像を加工できます。左がプレビュー、右が操作パネルです。

| 項目 | 内容 |
|---|---|
| 回転 | 左・右に90度ずつ回転 |
| 切り抜き | トグルをONにするか、プレビューをドラッグして範囲を指定（辺・角でサイズ変更、枠内で移動） |
| サイズ | 「吹き出しとの比率を維持」がONなら、切り抜いた分だけ画像を拡大して、吹き出しが画像に対して大きくなりすぎないようにする。「拡大縮小」スライダーで手動調整も可能 |
| 色の調整 | モノクロ、明るさ、コントラスト（50〜150%） |
| 取り消し | 直前の画像編集を元に戻す（最大3回まで。新しい画像やデータの読み込み、ページを閉じると履歴は消えます） |

適用すると、吹き出し・アンカー・凡例の位置も同じ変換で追従します。

## 画像として保存（PNG）
----

「画像として保存 (PNG)」で設定ダイアログを開き、左のプレビューを見ながら次を選びます。

- **書き出し範囲**: 背景画像のサイズで切り抜く／枠外にはみ出した要素も含める
- **背景**: 地図・白地を含める／透明にする（吹き出しと線だけを書き出す）
- **解像度**: 等倍・2倍・3倍（長辺は最大9,000pxまで。超える場合はボタンが押せなくなります）

「ダウンロード」を押すと、保存名の入力画面が表示されます。背景は元の高解像度画像で書き出されます。

## データの保存と自動保存
----

- **「データを保存 (.zip)」**: 配置データ（`project.json`）と元の地図画像を1つのZIPにまとめます。「データを読み込む (.zip)」で復元できます（現在のデータは上書きされます）。
- **自動保存**: 編集内容は、ブラウザの `localStorage` に自動で保存されます。次に開いたときに復元され、画面上部に案内が出ます。
  - 自動保存されるのは**配置データのみ**で、地図画像は含まれません。復元後は、画像を読み込み直してください。
  - ブラウザのデータを消去すると失われます。大切なデータは必ずZIPで保存してください。
- 他の人のZIPを開くときは、信頼できる相手のファイルだけを読み込んでください（読み込み時に値の検証をしていますが、念のため）。

## プライバシーと外部通信
----

入力した配置データや読み込んだ画像は、サーバーに送信されません（すべてブラウザ内で処理します）。
ただし、画面の表示のために、次の外部リソースを読み込みます。

- Google Fonts（Zen Kaku Gothic New）
- cdnjs（JSZip）
