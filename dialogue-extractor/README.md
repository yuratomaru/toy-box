# セリフ抽出ツール

小説やシナリオテキストなどの文章から、登場人物のセリフや話者を抽出・分類できるシングルページアプリです。

## 想定利用シーン
----

* 人称・口調ブレの確認(キャラごとの表記揺れ防止)
* 話者タグの記載ミス・抜けチェック
* 発言数のバランスチェック(特定キャラの喋りすぎ/不足調整)

## 機能
----

### データの編集・抽出・解析
* **高精度なセリフ自動抽出**:
  * 行頭の「話者タグ＋セリフ」(例：`母「おはよう」`)の判定(話者タグの最大文字数は抽出オプションで設定可能、既定は1文字)
  * カギカッコのみの行の抽出
  * `▼話者名`・`▼話者名のセリフ` のような見出し直後の連続発言の自動推定
  * 複数行にまたがるセリフの結合保持
* **人称辞書による自動判定・編集**:
  * 一人称・二人称・三人称の辞書を標準搭載
  * 検出された人称表現を抽出結果にハイライト表示し、話者推定をサポート
  * 単語の個別追加・削除、CSV/テキストファイルからのインポート、一括クリア・初期化に対応
* **話者整理・エイリアス機能**:
  * 「同じ話者として扱う」設定で、同一人物の別表記を単一グループに集約
  * 未確定・話者不明セリフに対する一括／個別割り当て
* **自動保存**: 編集内容や前回の抽出データは localStorage へ自動保存されます。

### 表示・デザイン
* **テーマ切替**: ライトテーマ / ダークテーマ対応。

### データの出力・活用
* **テキスト出力(ファイル保存)**: 話者ごとにまとめられたセリフデータを個別の `.txt` ファイルとして保存可能。

## 使い方
------

1. `index.html` をブラウザで開きます。
2. **「抽出したい文章を入力」** のエリアに対象テキストを貼り付けます。
3. **[抽出]** ボタンを押すとプレビュー・判定結果が自動生成されます。
4. 抽出結果を確認し、必要に応じて「人称辞書」の調整や「話者の割り当て・統合」を行います。
5. 話者ごとの **[txtで保存]** ボタンで、整理されたセリフデータをダウンロードできます。

## テキストの入力フォーマット・抽出ルール
------------------------------------

| 種別 | 表記例 | 抽出結果・判定ルール |
| :--- | :--- | :--- |
| **話者タグ付き** | `母「おはよう」`<br>`太郎「おはよう」` | 行頭の話者タグ＋セリフとして抽出され、話者名が自動割り当てされます。タグの最大文字数は **抽出オプション「話者タグの最大文字数」** で設定します(既定1文字、最大10文字。2以上にすると `太郎「…」` も話者付きになります)。変更後は **[抽出]** を押すと反映されます。 |
| **単体セリフ** | `「今日はいい天気だね」` | 行全体がセリフとして抽出されます(文中に紛れているセリフは対象外)。 |
| **見出し記法** | `▼太郎`<br>`「今日はいい天気だね」` | `▼話者名` の直後は、次の見出しや指定が来るまでのセリフがすべてその話者の発言として推定されます。 |
