# お品書き Viewer

同人イベントの頒布物リストを、スプレッドシートから貼り付けてプレビューできるシングルページアプリ。

**公開URL**: https://yuratomaru.github.io/toy-box/oshinagaki-viewer/

## 機能
----

### データの編集・操作
- **セル貼り付け・自動拡張**: スプレッドシートの範囲を貼り付けてリスト化(範囲外のデータは保持)。矢印キーや入力時にマス目が自動で広がります。
- **データコピー・復元**: 表の内容をタブ区切りでコピーし、スプレッドシートへの貼り戻しが可能。
- **Undo / Redo**: `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`(または `Ctrl+Y`)で編集履歴を操作(表示設定は対象外)。
- **行移動・削除**: プレビュー上のボタンやショートカット(`Alt+↑/↓` で移動、`Alt+Delete/Backspace` で削除)で操作可能。※並び替え反映中のみ移動は無効。
- **一括クリア**: 誤操作を防ぐ確認ダイアログ付き。
- **自動保存**: 編集データは `localStorage` へ自動保存されます。

### 表示・デザイン
- **表示モード切替**: カード表示とテーブル表示を選択可能(テーブル表示では「サークル名」列の幅をドラッグで調整可能)。
- **テーマ切替**: ライトテーマ / ダークテーマ対応。
- **カテゴリ自動着色**: CUDパレット準拠の5色で自動分類(セット：赤紫／新刊：朱赤／既刊：青／グッズ：緑／その他：橙)。

### 並び替え(ソート)
- 基本は「入力順」。「配置順」「カテゴリ順」はオプション選択後に「並び替えを反映」を押して適用。

### 撮影・公開機能
- **撮影モード(UI非表示)**: 購入チェックなどの非公開要素を隠し、プレビュー領域のみを見た目そのままPNG画像として保存可能。終了すると自分用表示へ自動で戻ります。

## 使い方
----

1. `index.html` をブラウザで開く
2. スプレッドシート(Google Sheets / Excel)のセルをコピーして貼り付け
3. プレビューが自動生成されます

## スプレッドシートの列構成
----

| 列 | 内容 | 例 |
|---|---|---|
| A | 配置 | `土 え12a` |
| B | サークル名 | `サークル名` |
| C | 頒布物名 | `本のタイトル` |
| D | カテゴリ | `新刊` / `既刊` / `グッズ` / `セット` |
| E | 頒布価格 | `500` / `無料` |
| F | 備考 | `委託あり` |

1行目はヘッダー行として自動でスキップされます。カテゴリは「セット」を含む文字列が最優先で判定され、次に「新刊」「既刊」「グッズ」の順でキーワード一致します。いずれにも一致しない分類はすべて「その他」(橙)として表示されます。

購入済みの管理はデータ貼り付け時には行わず、プレビュー画面のチェックボックスで管理します(データには含まれません)。

「カテゴリ順」を反映した場合、同一サークルで複数の頒布物があるときのプレビュー内の並び順は「セット → 新刊(分類が完全に「新刊」のもの)→ 新刊(前後に文字が付くもの。例：準新刊)→ それ以外」の優先順位になります。

## ファイル構成
----

```
shopping-list-viewer/
├── index.html        # エントリーポイント(画像保存用に html2canvas をCDNから読み込み)
├── src/
│   ├── style.css     # スタイル(CSSカスタムプロパティ、ダークテーマ)
│   └── main.js       # アプリロジック(IIFE。画像保存機能のみ html2canvas に依存)
└── README.md
```

画像保存機能はCDN(cdnjs.cloudflare.com)から `html2canvas` を読み込むため、利用時はインターネット接続が必要です。
