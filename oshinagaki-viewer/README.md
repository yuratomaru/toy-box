# お品書き Viewer

同人イベントの頒布物リストを、スプレッドシートから貼り付けてプレビューできるシングルページアプリです。

## 機能

- スプレッドシートのセルを貼り付けてリスト化（矢印キー・入力でマス目が自動拡張）
- カード表示 / テーブル表示の切り替え（テーブル表示は「サークル名」列の幅をドラッグで調整可能）
- 撮影モードにすると自動で公開用表示（購入チェックを隠す）に切り替わり、終了すると自分用表示に戻る
- 撮影モード中は、プレビューゾーンのみをPNG画像として保存可能（列幅調整などその時点の見た目をそのまま書き出し）
- スペース順 / 入力順の並び替え
- カテゴリタグは5色の固定パレットで自動カラーリング（セット：赤紫／新刊：朱赤／その他：橙／グッズ：緑／既刊：青、CUDパレット準拠）
- ライト / ダークテーマ対応
- 撮影モード（UI非表示でスクリーンショット向け）
- データは `localStorage` に自動保存

## 使い方

1. `index.html` をブラウザで開く
2. スプレッドシート（Google Sheets / Excel）のセルをコピーして貼り付け
3. プレビューが自動生成されます

## スプレッドシートの列構成

| 列 | 内容 | 例 |
|---|---|---|
| A | 配置 | `土 え12a` |
| B | サークル名 | `サークル名` |
| C | 頒布物名 | `本のタイトル` |
| D | カテゴリ | `新刊` / `既刊` / `グッズ` / `セット` |
| E | 頒布価格 | `500` / `無料` |
| F | 備考 | `委託あり` |

1行目はヘッダー行として自動でスキップされます。カテゴリは「セット」を含む文字列が最優先で判定され、次に「新刊」「既刊」「グッズ」の順でキーワード一致します。いずれにも一致しない分類はすべて「その他」（橙）として表示されます。

購入済みの管理はデータ貼り付け時には行わず、プレビュー画面のチェックボックスで管理します（データには含まれません）。

同一サークルで複数の頒布物がある場合、プレビュー内の並び順は「セット → 新刊（分類が完全に「新刊」のもの）→ 新刊（前後に文字が付くもの。例：準新刊）→ それ以外」の優先順位になります。

## ファイル構成

```
shopping-list-viewer/
├── index.html        # エントリーポイント（画像保存用に html2canvas をCDNから読み込み）
├── src/
│   ├── style.css     # スタイル（CSSカスタムプロパティ、ダークテーマ）
│   └── main.js       # アプリロジック（IIFE。画像保存機能のみ html2canvas に依存）
└── README.md
```

画像保存機能はCDN（cdnjs.cloudflare.com）から `html2canvas` を読み込むため、利用時はインターネット接続が必要です。
